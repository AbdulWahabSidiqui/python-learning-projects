# Python Learning Projects



A collection of additional Python projects built while learning Python programming, automation, GUI development, and web development.



This repository contains projects that I want to maintain separately from my main portfolio and data analysis repositories.



## Projects



### 1. Space Invader

A Python game project focused on game logic, keyboard controls, and interactive gameplay.



**\*Technologies:\*\* Python, Pygame



### 2. Breakout

A classic arcade-style game project involving paddle movement, ball physics, collision detection, and scoring.



**\*Technologies:\*\* Python, Pygame



### 3. Dangerous Writing App

A writing application designed to encourage continuous writing without stopping for too long.



**\*Technologies:\*\* Python, Tkinter



### 4. Flask To-Do App

A task management application built to practise Python web development and Flask.



**\*Technologies:\*\* Python, Flask



### 5. Image Watermarking App

An application for adding watermarks to images.



**\*Technologies:\*\* Python, GUI development



### 6. PDF to Audiobook Converter

A project that converts text extracted from PDF documents into spoken audio.



**\*Technologies:\*\* Python, PDF processing, text-to-speech
